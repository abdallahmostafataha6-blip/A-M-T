A-M-T Knowledge Center · Version 1.9.1

Online Installation Guide

Follow these four steps to install A-M-T, choose optional AI integration components, and verify that the add-in is available in Autodesk Revit.

BEFORE YOU START — WINDOWS WARNING
  1. 1. Download the installer from the Download page (it always offers the latest release).
  2. 2. The installer is not signed with a paid certificate, so Windows may show "Windows protected your PC". Click More info, then Run anyway.
  3. 3. To make sure the file is the original, compare its SHA-256 (shown on the Download page) with the file you downloaded: in PowerShell run Get-FileHash .\A-M-T-Setup-1.9.1.exe.
STEP 01 — SELECT REVIT VERSIONS
  1. 1. Select every Revit version installed on this computer. Multiple versions can be selected.
  2. 2. The example shows Revit 2024 and 2025 selected; 2023 and 2026 are not selected.
  3. 3. Close Revit before installing. The installer notes that selected A-M-T files will be replaced.
  4. 4. Installation is per-user; the installer states that administrator access is not required.
STEP 02 — CHOOSE AI CLIENTS
  1. 1. This option is optional. Enable it only if you want the installer to install/configure supported AI clients and the local A-M-T MCP bridge.
  2. 2. Available client choices shown: ChatGPT + Codex, Claude Desktop, DeepSeek Harness, OpenCode and Cursor.
  3. 3. Required runtimes shown: Python and .NET SDK 8. Node.js is required only for OpenCode.
  4. 4. Apps that are already installed are skipped; only their A-M-T settings are written (Claude, Cursor, Codex, OpenCode).
  5. 5. If Claude, Cursor, ChatGPT or Codex is open, setup offers to close it and open it again when it finishes, so it loads the new A-M-T tools.
STEP 03 — INSTALLATION COMPLETE
  1. 1. The confirmation dialog reports that A-M-T was installed successfully, with one line per AI app.
  2. 2. The installer progress area shows Installation complete and a full progress bar.
  3. 3. Files are installed in %APPDATA%\Autodesk\Revit\Addins\<year>\A-M-T and the MCP server in %LOCALAPPDATA%\A-M-T\mcp. Older EL-T0P files are removed and your settings are kept.
  4. 4. Later updates can be installed from Revit with Settings → Check for Updates.
STEP 04 — VERIFY THE A-M-T RIBBON IN REVIT
  1. 1. Open Autodesk Revit after installation and locate the A-M-T tab in the ribbon.
  2. 2. Confirm that the expected tool groups are visible: Sheets & Views, Export, Walls & Structure, Finishes, Settings and MCP.
  3. 3. The screenshot shows the A-M-T tab loaded in Autodesk Revit 2025.
