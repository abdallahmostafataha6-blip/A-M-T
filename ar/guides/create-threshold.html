دليل أوامر A-M-T · 14

Create Threshold

إنشاء أرضيات العتبات تلقائيًا أسفل الأبواب المستوفية للشروط.

التشطيباتإنشاء الأرضيات تلقائيًا

طريقة عمل الأمر

يفحص Create Threshold الأبواب داخل النطاق المختار، وينشئ أرضية أسفل كل باب مستوفٍ للشروط لا توجد تحته أرضية. تختار نوع الأرضية وأقل عرض للباب والنطاق قبل تشغيل الأمر.

  1. اختر نوع الأرضية المستخدم للعتبات.
  2. حدد أقل عرض للباب بالمليمتر.
  3. اختر Entire project أو Active view أو Current selection.
  4. اضغط Create وراجع تقرير النتيجة.

اضبط إعدادات العتبة

01 · اضبط باراميترات العتبة

Floor type for the threshold: اختر نوع الأرضية في Revit الذي سيُنشأ أسفل الأبواب. المثال يستخدم Concrete 100mm w VCT.

Only doors with width ≥ (mm): أدخل أقل عرض للباب. في المثال القيمة 600 mm، والأبواب الأضيق من ذلك يتم استبعادها.

Scope: حدد أين يبحث الأمر:

  • Entire project — معالجة الأبواب في المشروع كله.
  • Active view — معالجة الأبواب الظاهرة في الـ View الحالي.
  • Current selection — معالجة الأبواب المحددة حاليًا في Revit.

اضغط Create لتنفيذ العملية، أو Cancel للإغلاق دون إنشاء أرضيات.

راجع تقرير الإنشاء

02 · افهم النتيجة

عند انتهاء الأمر، يلخص التقرير النتيجة:

  • Thresholds created: عدد أرضيات العتبات الجديدة التي تم إنشاؤها.
  • Skipped (floor already under door): أبواب توجد أسفلها أرضية بالفعل.
  • Skipped (other): أبواب تم استبعادها لسبب آخر.

في هذا المثال تم إنشاء 7 عتبات، مع تخطي 0 لوجود أرضية بالفعل و0 لأسباب أخرى.

تحقق من أرضيات العتبات في Revit

03 · افحص الأرضيات المُنشأة

تظهر العتبات المُنشأة كعناصر أرضيات عند فتحات الأبواب. يوضح المثال الأرضيات المُنشأة محددة في المسقط، ولوحة Properties تعرّف العنصر المحدد بأنه Floor بالنوع المختار.

راجع فتحات الأبواب في المسقط وتأكد أن أرضيات العتبات في أماكنها المتوقعة.

شاهد Create Threshold أثناء العمل

تابع خطوات الأمر كاملة داخل Autodesk Revit.

قبل تشغيل الأمر

  • تأكد أن نوع الأرضية المطلوب موجود في المشروع.
  • اضبط أقل عرض للباب بما يناسب متطلبات مشروعك.
  • اختر نطاق المعالجة الصحيح قبل إنشاء العتبات.
  • راجع تقرير النتيجة وافحص الأرضيات المُنشأة في المسقط.
