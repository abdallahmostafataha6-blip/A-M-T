دليل أوامر A-M-T · 07

CW Types

إنشاء أنواع الحوائط الساترة تلقائيًا من مجموعات الأطوال والارتفاعات المختلفة.

الحوائط والإنشاءشرح مرئي

عن هذا الأمر

يفحص CW Types الحوائط الساترة ويجمعها حسب أطوالها وارتفاعاتها المختلفة، وينشئ نوعًا مستقلًا لكل مجموعة، ثم يخصص الأنواع المُنشأة للحوائط المطابقة. أنواع الحوائط الساترة الموجودة لا تتغير.

المثال المعروض: يكتشف الأمر 10 مجموعات طول / ارتفاع في 14 حائطًا ساترًا. وعند ضبط أول Type Mark على CW01، ويعرض معاينة للعلامات المُنشأة بدءًا من CW01.

طريقة عمل الأمر

01 · افحص الحوائط الساترةشغّل CW Types من شريط أدوات A-M-T. يحدد الأمر الحوائط الساترة ويقرأ أطوالها وارتفاعاتها.
02 · راجع مجموعات الأنواعأدخل أول Type Mark وراجع مجموعات الطول × الارتفاع المكتشفة وعدد الحوائط في كل مجموعة.
03 · الإنشاء والتخصيصاضغط إنشاء الأنواع. ينشئ A-M-T الأنواع الجديدة ويخصصها للحوائط الساترة المطابقة.

شرح الأمر

01 · حدد أول Type Mark

أدخل العلامة الأولى في First type mark (مثلًا CW01). يستخدمها A-M-T كبداية لتسلسل علامات الأنواع المُنشأة.

يعرض شريط الملخص عدد مجموعات الطول / الارتفاع المختلفة وإجمالي الحوائط الساترة المكتشفة. ويعرض الجدول معاينة لكل مجموعة مع Type mark وLength × Height وعدد Walls.

02 · راجع تقرير الإنشاء

بعد الضغط على Create types، تؤكد نافذة النتيجة عدد الأنواع الجديدة، وعدد الحوائط التي خُصصت لها، وما إذا كانت أنواع الحوائط الساترة الموجودة بقيت دون تغيير.

في هذا المثال تم إنشاء 10 أنواع جديدة وتخصيصها لـ 14 حائطًا. وبقيت أنواع CW الموجودة دون تغيير.

03 · تابع توثيق الحوائط الساترة

يعرض الفيديو أيضًا أمر Curtain wall views and sheets المرتبط، الذي يتيح اختيار قوالب Callouts المساقط والواجهات والقطاعات، ثم تحديد أول Type Mark ورقم أول Sheet واسم الـ Sheet والـ Title Block.

يتحكم خيار Include curtain walls from links في شمول الحوائط الساترة من النماذج المرتبطة في هذا التوثيق.

ملاحظة: هذا أمر منفصل عن CW Types، ويظهر هنا كخطوة تالية في سير العمل المسجّل.

شاهد CW Types أثناء العمل

يعرض الفيديو اختيار الحوائط الساترة، ومراجعة المجموعات المكتشفة، وإنشاء الأنواع، والتحقق من خصائص الحوائط الساترة الناتجة.

قائمة مراجعة سريعة

✓ افتح View في Revit يحتوي على الحوائط الساترة التي تريد معالجتها.

✓ شغّل CW Types من شريط أدوات A-M-T.

✓ أدخل أول Type Mark وراجع مجموعات الطول / الارتفاع.

✓ اضغط Create types وراجع تقرير الإنشاء.

✓ حدد حائطًا ساترًا وتأكد من نوعه في Properties / Type Properties في Revit.
