مركز معرفة A-M-T · الإصدار 1.9.1

دليل التثبيت على الإنترنت

اتبع هذه الخطوات الأربع لتثبيت A-M-T، واختيار مكونات التكامل الاختيارية مع الذكاء الاصطناعي، والتأكد من ظهور الإضافة في Autodesk Revit.

قبل البدء — تحذير Windows
  1. 1. حمّل ملف التثبيت من صفحة التحميل (يعرض دائمًا أحدث إصدار).
  2. 2. المثبّت غير موقّع بشهادة مدفوعة، لذلك قد يظهر في Windows "Windows protected your PC". اضغط More info، ثم Run anyway.
  3. 3. للتأكد أن الملف هو الأصلي، قارن قيمة SHA-256 (الظاهرة في صفحة التحميل) بالملف الذي حمّلته: شغّل في PowerShell الأمر Get-FileHash .\A-M-T-Setup-1.9.1.exe.
الخطوة 01 — اختر إصدارات Revit
  1. 1. اختر كل إصدارات Revit المثبتة على هذا الجهاز. يمكن اختيار أكثر من إصدار.
  2. 2. يوضح المثال اختيار Revit 2024 و2025، بينما لم يتم اختيار 2023 و2026.
  3. 3. أغلق Revit قبل التثبيت. ينبّه المثبّت إلى أن ملفات A-M-T المختارة سيتم استبدالها.
  4. 4. التثبيت لكل مستخدم على حدة، ولا يحتاج إلى صلاحيات المسؤول.
الخطوة 02 — اختر تطبيقات الذكاء الاصطناعي
  1. 1. هذا الخيار اختياري. فعّله فقط إذا أردت أن يثبّت المثبّت تطبيقات الذكاء الاصطناعي المدعومة ويضبطها مع جسر A-M-T MCP المحلي.
  2. 2. التطبيقات المتاحة: ChatGPT + Codex وClaude Desktop وDeepSeek Harness وOpenCode وCursor.
  3. 3. المتطلبات الظاهرة: Python و.NET SDK 8. أما Node.js فمطلوب لـ OpenCode فقط.
  4. 4. التطبيقات المثبتة مسبقًا يتم تخطي تثبيتها، ويتم فقط كتابة إعدادات A-M-T الخاصة بها (Claude وCursor وCodex وOpenCode).
  5. 5. إذا كان Claude أو Cursor أو ChatGPT أو Codex مفتوحًا، يعرض المثبّت إغلاقه وإعادة فتحه بعد الانتهاء حتى يحمّل أدوات A-M-T الجديدة.
الخطوة 03 — اكتمال التثبيت
  1. 1. تؤكد رسالة الإنهاء أن A-M-T تم تثبيته بنجاح، مع سطر لكل تطبيق ذكاء اصطناعي.
  2. 2. تعرض منطقة التقدم في المثبّت عبارة Installation complete مع شريط تقدم مكتمل.
  3. 3. يتم تثبيت الملفات في %APPDATA%\Autodesk\Revit\Addins\<year>\A-M-T، وخادم MCP في %LOCALAPPDATA%\A-M-T\mcp. تُحذف ملفات EL-T0P القديمة وتُحفظ إعداداتك.
  4. 4. يمكن تثبيت التحديثات اللاحقة من داخل Revit عبر Settings ← Check for Updates.
الخطوة 04 — تحقق من شريط أدوات A-M-T في Revit
  1. 1. افتح Autodesk Revit بعد التثبيت وابحث عن تبويب A-M-T في شريط الأدوات.
  2. 2. تأكد من ظهور مجموعات الأدوات المتوقعة: Sheets & Views وExport وWalls & Structure وFinishes وSettings وMCP.
  3. 3. تُظهر الصورة تبويب A-M-T محمّلًا في Autodesk Revit 2025.
