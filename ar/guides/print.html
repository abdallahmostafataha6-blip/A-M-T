Print

صدّر Sheets وViews مختارة من Revit إلى PDF وDWG في خطوات موجّهة واحدة.

التصديرPDF وDWGشرح مرئي

طريقة عمل الأمر

يعمل أمر Print في ثلاث خطوات: أولًا اختر الـ Sheets أو الـ Views، ثم اضبط صيغ التصدير وإعداداتها، وأخيرًا اختر مجلد الإخراج وابدأ التصدير.

01 · الاختياراختر الـ Sheets أو الـ Views القابلة للطباعة وراجع ترتيب اسم الملف.
02 · الصيغفعّل PDF أو DWG أو كليهما، ثم راجع إعدادات كل صيغة.
03 · مكان الحفظاختر المجلد الرئيسي وحدد طريقة تنظيم الملفات المُصدّرة.

شرح خطوة بخطوة

01 · اختر الـ Sheets أو الـ Views

استخدم قائمة Show للتبديل بين Sheets وViews. ابحث بالاسم أو الرقم، ثم علّم العناصر المطلوب تصديرها. استخدم Select all أو Clear selection لإدارة القائمة بسرعة. ترتيب اسم الملف الظاهر هو Sheet Number › Sheet Name، واستخدم Custom files name عندما تحتاج نمط تسمية مخصصًا. اضغط Next عندما تصبح مجموعة التصدير جاهزة.

02 · اضبط إخراج PDF

فعّل PDF وراجع إعدادات PDF في Revit. تشمل الخيارات الظاهرة: الإخراج النقطي، وجودة التصدير، وعمق الألوان، وإظهار حدود الـ Crop، والمستويات المرجعية، والـ Scope Boxes، وعلامات الـ Views غير المرتبطة، واتجاه الورقة وموضعها، وجودة الصور النقطية، ولون الـ Views المرتبطة، ونوع التكبير ونسبته. وتوضح الملاحظة في النافذة أن الـ Sheets تحتفظ بمقاسها، أما الـ Views المنفصلة فيختار لها A-M-T أصغر مقاس ورق قياسي يناسب الـ Crop بمقياس الـ View ونسبة التكبير. ويتجاهل Revit إعدادات التكبير عند تصدير الـ Sheets.

03 · اضبط إخراج DWG

فعّل DWG وانتقل إلى إعدادات CAD. اختر إعداد تصدير من Revit من القائمة. تشير النافذة إلى أنه يمكن إنشاء Export Group من Revit’s DWG Export > Modify Export Setup. الخيارات الإضافية الظاهرة هي تصدير الـ Views على الـ Sheets واللينكات كمراجع خارجية، ودمج الصور كملفات OLE، وحذف ملفات ‎.pcp بعد التصدير. والخياران الأخيران مُعلَّمان بأنهما غير متاحين في واجهة تصدير Revit (API).

04 · حدد مكان الإخراج

اختر مجلدًا رئيسيًا بكتابة المسار أو باستخدام Browse. ثم اختر طريقة تنظيم الإخراج: Save all files in the same folder location أو Save and split files by file format. عند اختيار الخيار الثاني، يتم إنشاء مجلدين منفصلين لـ PDF وDWG داخل المجلد الرئيسي. راجع مسارات الحفظ الظاهرة قبل الضغط على Export.

05 · راجع نتيجة التصدير

عند انتهاء المعالجة، تعرض نافذة النتيجة عدد عمليات التصدير المكتملة والفاشلة. في التشغيل المصوّر اكتمل 6 من 6 وفشل 0. استخدم Open folder لفحص الملفات المُنشأة، أو Close للعودة إلى Revit.

دمج الكل في ملف PDF واحد

في الخطوة 2 (Export formats)، تبدأ إعدادات PDF بخيار Combine all into one PDF file. علّمه واكتب اسم الملف، فتصبح كل Sheet وكل View مختار صفحةً في ملف PDF واحد بترتيب القائمة. ويتم حفظ الاسم الذي تكتبه للمرة القادمة.

  • كل صفحة تحتفظ بمقاس الـ Sheet أو الـ View الخاص بها.
  • تصدير DWG لا يتأثر: ملف DWG لكل Sheet أو View كما كان.
  • إذا كان هناك ملف بنفس الاسم، يسألك Print قبل استبداله.

شاهد Print أثناء العمل

تابع خطوات الاختيار وضبط الصيغ والتصدير كاملة داخل Autodesk Revit.

قبل التصدير

  • تأكد من اختيار الـ Sheets أو الـ Views الصحيحة.
  • فعّل صيغة إخراج واحدة على الأقل: PDF أو DWG.
  • راجع إعدادات PDF وCAD كلًا على حدة.
  • تأكد من المجلد الرئيسي وطريقة تنظيم الملفات.
  • بعد التصدير، راجع أعداد الملفات الناجحة والفاشلة، ثم افتح مجلد الإخراج.
