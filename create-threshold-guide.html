A-M-T Command Guide · 14

Create Threshold

Automatically create threshold floors beneath qualifying doors.

FinishesAutomated floor creation

How the command works

Create Threshold checks doors in the selected scope and creates a floor beneath each qualifying door that does not already have a floor under it. You choose the floor type, minimum door width, and scope before running the command.

  1. Choose the floor type to use for thresholds.
  2. Set the minimum door width in millimetres.
  3. Choose Entire project, Active view, or Current selection.
  4. Click Create and review the result report.

Configure the threshold settings

01 · Set the threshold parameters

Floor type for the threshold: choose the Revit floor type that will be created beneath the doors. The example uses Concrete 100mm w VCT.

Only doors with width ≥ (mm): enter the minimum door width. In the example, the value is 600 mm; doors narrower than this threshold are excluded.

Scope: choose where the command searches:

  • Entire project — process doors throughout the project.
  • Active view — process doors visible in the current view.
  • Current selection — process the doors in the current Revit selection.

Click Create to run the operation, or Cancel to close without creating floors.

Review the creation report

02 · Understand the result

When the command finishes, the report summarizes the outcome:

  • Thresholds created: number of new threshold floors created.
  • Skipped (floor already under door): doors that already have a floor beneath them.
  • Skipped (other): doors excluded for another reason.

In this example, 7 thresholds were created, with 0 skipped because a floor already existed and 0 skipped for other reasons.

Verify the threshold floors in Revit

03 · Check the generated floors

The created threshold elements appear as floor elements at the door openings. The example shows the generated floors selected in the plan, with the Properties palette identifying the selected element as a Floor using the chosen type.

Review the door openings in the plan and confirm that the threshold floors are placed where expected.

Before you run the command

  • Confirm that the required floor type is available in the project.
  • Set the minimum door width to match your project requirements.
  • Choose the correct processing scope before creating thresholds.
  • Review the result report and inspect the generated floors in plan.
