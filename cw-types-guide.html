A-M-T Command Guide · 07

CW Types

Automatically create curtain wall types from distinct wall length and height groups.

Walls & StructureVisual walkthrough

About this command

CW Types scans curtain walls, groups them by their distinct length and height, creates a separate curtain wall type for each group, and assigns the generated types to the matching walls. Existing curtain wall types are left unchanged.

Example shown: The command detects 10 length / height groups across 14 curtain walls. With the first type mark set to CW01, it previews the generated marks from CW01 onward.

How the command works

01 · Scan curtain wallsRun CW Types from the A-M-T ribbon. The command identifies curtain walls and reads their length and height.
02 · Review type groupsEnter the first type mark and review the detected length × height groups and the number of walls in each group.
03 · Create and assignClick Create types. A-M-T creates the new types and assigns them to the matching curtain walls.

Command walkthrough

01 · Set the first type mark

Enter the starting mark in First type mark (for example, CW01). A-M-T uses this as the beginning of the generated type-mark sequence.

The summary bar reports the number of distinct length / height groups and the total number of curtain walls detected. The table previews each group with its Type mark, Length × Height, and Walls count.

02 · Review the creation report

After clicking Create types, the result dialog confirms how many new types were created, how many walls were assigned, and whether any existing curtain wall types were left unchanged.

In this example, 10 new types were created and assigned to 14 walls. Existing CW types were left unchanged.

03 · Continue with curtain wall documentation

The demonstration also shows the related Curtain wall views and sheets command. It lets you choose templates for plan callouts, elevations, and sections, then define the first type mark, first sheet number, sheet name, and title block.

The Include curtain walls from links option controls whether linked-model curtain walls are included in that documentation workflow.

Note: this is a separate command from CW Types; it is shown here as the next step in the recorded workflow.

Quick checklist

✓ Open a Revit view containing the curtain walls you want to process.

✓ Run CW Types from the A-M-T ribbon.

✓ Enter the first type mark and review the length / height groups.

✓ Click Create types and check the creation report.

✓ Select a curtain wall and verify its assigned type in Revit Properties / Type Properties.
