FAQ & troubleshooting

Quick answers to the questions we hear most. Still stuck? Report an issue or contact us.

Installation

Is A-M-T free?

Yes. A-M-T is free to download and use.

Which Revit versions are supported?

Autodesk Revit 2023, 2024, 2025 and 2026 on Windows 10 and 11.

Windows says "Windows protected your PC". Is the installer safe?

The installer is not signed with a paid certificate, so Windows does not know it yet. Click More info, then Run anyway. To check that the file is the original, compare its SHA-256 with the one on the Download page (PowerShell: Get-FileHash .\A-M-T-Setup-x.y.z.exe).

Do I need administrator rights?

No. A-M-T installs for your Windows user only. Optional extras (PDF24, some AI apps) may ask for administrator approval.

The A-M-T tab does not appear in Revit.

Close Revit completely and open it again: a new version loads the next time Revit starts. Check that the setup was run for your Revit version. If Revit shows a message about the add-in, send us a screenshot.

Where are the A-M-T files?

Add-in: %APPDATA%\Autodesk\Revit\Addins\<year>\A-M-T. Settings and logs: %APPDATA%\A-M-T. MCP server: %LOCALAPPDATA%\A-M-T\mcp. Versions before 1.9.1 used the name EL-T0P; the setup moves everything automatically.

Updates

How do I update?

In Revit open the A-M-T tab, Settings, Check for Updates. It downloads the latest release from GitHub, checks its SHA-256 and installs it; the new version loads the next time Revit starts. You can also download the setup again from this site.

See the changelog.

AI apps and MCP

Claude (or another AI app) does not show the A-M-T tools.

Open Revit, A-M-T tab, MCP Host, and check the Status section. Press Fix AI app settings, then close the AI app completely (also from the tray next to the clock) and open it again. AI apps read their tools only when they start.

"Cannot reach A-M-T in Revit".

Revit must be open with a file, and the MCP bridge must be on: MCP Host, tick Enable A-M-T MCP bridge, OK.

The AI says the versions are different.

The MCP server and the add-in in Revit come from different setups. Install the latest setup, restart Revit and close and reopen the AI app.

Can the AI change my model without asking?

Only if you choose so. In MCP Host you pick when Revit asks before a change: read-only, ask before every change, ask before deleting only, ask before edits only, or automatic. Running C# code always asks unless you choose Automatic.

Tools

DIMS EX&IN made a wrong or missing dimension.

Every run saves a log on the Desktop (A-M-T_Dims_log.txt) and copies it to the clipboard. Send it with a screenshot of the view so we can fix it.

PRINT says "The managed object is not valid".

This was fixed in 1.9.0: update A-M-T. If it still happens, send %APPDATA%\A-M-T\print-errors.log.

Report a problem

Open a new issue on GitHub and fill in the form: A-M-T version, Revit version, what you did and what happened. Logs and screenshots help a lot.
