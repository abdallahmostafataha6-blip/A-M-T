A-M-T Command Guide · 04

Curtain Wall

Generate coordinated curtain wall plans, elevations, sections and sheets.

Walls & StructureVisual walkthrough

How the command works

The Curtain Wall command creates documentation views for curtain wall types and organizes them on a dedicated sheet. Set the view templates, naming and sheet details, choose whether linked curtain walls are included, then run the command and review its report.

  1. Choose the plan, elevation and section view templates.
  2. Set the first type mark, first sheet number, sheet name and title block.
  3. Choose whether curtain walls from linked models should be included, then click Create.
  4. Review the creation report and open the generated sheet.

Configure the curtain wall documentation

01 · Set up views and sheet information

Choose the view template for each generated view category:

  • Template: plan callouts — controls the plan callout views.
  • Template: elevations — controls the curtain wall elevation views.
  • Template: sections — controls the section views.

Then define the documentation identity:

  • First type mark — starting mark for the curtain wall types (example: CW01).
  • First sheet number — starting sheet number (example: A-701).
  • Sheet name — name assigned to the generated sheet (example: CURTAIN WALL TYPES).
  • Title block type — select the title block used for the sheet.

Enable Include curtain walls from links if linked models should also be considered. Click Create when the setup is ready.

Review the creation report

02 · Check the results before closing

After processing, the command displays a summary of the generated documentation. In the example shown:

  • Types: 10
  • Sheets: 3
  • Views: 30
  • Issues: 0

The report also identifies the detected sheet layout: A0, with a 1000 × 800 mm drawing area and a 100 mm grid. Review the issue count and layout information, then click OK.

Inspect the generated curtain wall sheet

03 · Review the drawing layout

Open the generated sheet to inspect the documentation placed on it. The example shows several curtain wall types arranged with their related views:

  • Plan views along the lower part of the sheet.
  • Elevation views showing the curtain wall configuration.
  • Section views alongside the corresponding elevations.

Check that the views are legible, correctly arranged and associated with the intended curtain wall types. The example sheet is numbered A-701 and named CURTAIN WALL TYPES.

Before you run the command

  • Confirm that the required plan, elevation and section view templates exist in the project.
  • Choose a starting type mark and sheet number that fit your project naming convention.
  • Select the correct title block type for the intended sheet layout.
  • Enable linked curtain walls only when linked-model elements should be included.
  • After creation, review the report and inspect the generated sheet in Revit.
