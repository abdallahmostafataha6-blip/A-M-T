Getting started

Install A-M-T in a few steps

Use the published release package and follow the installation information provided with it.

Download the installer

Download A-M-T-Setup from the button above. If Windows shows "Windows protected your PC", click More info, then Run anyway: the installer is safe but not signed with a paid certificate.

Run the setup

Close Revit, choose your Revit versions and, if you want, the AI apps to connect. Follow the installation guide for every step.

Open Autodesk Revit

Launch Revit and open the A-M-T tab. Later versions can be installed from Revit with Check for Updates.

Compatibility: Windows 10 / 11 · Autodesk Revit 2023, 2024, 2025 and 2026. Free to use. Problems or ideas? See the FAQ or report an issue.
