Getting started

Install A-M-T in a few steps

Use the published release package and follow the installation information provided with it.

Download the release

Open the latest GitHub release and download the installation package listed under its release assets.

Follow the package instructions

Review any included README or installation notes and follow the steps supplied with that release.

Open Autodesk Revit

Launch Revit and look for the A-M-T ribbon tab. If it does not appear, check the release notes and installation guidance.

Compatibility: A-M-T is a Windows add-in for Autodesk Revit. Check the latest release notes and package details for the Revit versions supported by that release.
