Help

Frequently asked questions

Where should I start if A-M-T is not installed?

Start with the illustrated Installation Guide, then use the Quick User Guide to become familiar with the toolkit.

Where can I find instructions for a specific command?

Open the Command Guides collection and select the PDF matching the command name.

Are the command guides separate from the Quick Guide?

Yes. The Quick Guide provides an overview, while the Command Guides contain individual documentation for the 17 commands.

Which version do these guides cover?

The Installation Guide and Quick Guide linked here are the A-M-T 1.8.8 documents.

Need the latest A-M-T release?

Visit the official releases page to download the current version.
